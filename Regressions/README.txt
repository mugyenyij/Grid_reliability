### Appliance Regression ###

The script "appliance_regressions" contains code conducted to create our regression results showing the impact of reliability challenges on;
1. Total Appliance ownership
2. Ownership of specific appliances i.e Radios, TVs, Phones etc

### Conditional Demand ###
The script "conditional_demand.R" contains regression anaysis done to estimate monthly household demand as shown in section 4 of our paper

### Consumption simulation ###

The script "consumption_simulations.R" contains code showing how we created the distributions in section 4 estimating how household 
consumption might have if grid reliablity was improved. 

### Descriptive Statitics ###

The script "descriptive_statistics.R" contains code showing how created output that shows the ownership distribution of different 
household appliances amongst households in our survey

### Prepare regression data ###

This contains code that creates clean input data for our regression analysis.
